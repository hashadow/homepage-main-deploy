量化志

🌟 金融 × Python × 量化学习总框架（Hanz 版）

目标： 建立一个稳定、体系化、可长期积累的知识结构。
组成： 金融基础 + 数学统计 + Python 数据分析 + 量化策略开发 + 项目实践。

1. 金融基础（Finance Basics）

1.1 货币时间价值（Time Value of Money）

  • 折现率（Discount Rate）
  • 现值/终值（PV/FV）
  • 年金、永续年金

1.2 公司金融（Corporate Finance）

  • 资本结构（加权平均资本成本 WACC）
  • 项目评估（NPV、IRR）
  • 股利政策
  • 融资方式（股权、债权、银行融资）

1.3 投资学（Investments）

  • 风险与收益（Mean-Variance）
  • CAPM、Beta、Alpha
  • 资产组合理论（Portfolio Theory）
  • 市场有效性（EMH）

1.4 金融市场与机构（Financial Markets）

  • 一级/二级市场
  • 证券公司、基金公司、银行、保险
  • 监管体系

1.5 固定收益（Fixed Income）

  • 债券定价（价格、收益率）
  • 久期/凸性
  • 利率风险

1.6 衍生品（Derivatives）

  • 期货、期权基础
  • Black-Scholes 模型
  • Delta/Gamma/Vega/Rho
  • 对冲与套利

1.7 国际金融（International Finance）

  • 汇率机制
  • 外汇市场
  • 跨境资本流动

2. 经济学基础（Economics Basics）

2.1 微观经济学

  • 供需模型
  • 弹性
  • 市场结构（完全竞争/寡头/垄断）
  • 博弈论

2.2 宏观经济学

  • GDP、通胀、失业
  • 财政政策/货币政策
  • 经济周期
  • 国际收支与汇率

3. 数学与统计基础（Math & Statistics）

3.1 数学基础

  • 微积分（变化率、最优化）
  • 线性代数（向量、矩阵）
  • 随机过程基础（布朗运动）

3.2 概率与统计

  • 概率分布（正态、t、卡方）
  • 点估计/区间估计
  • 假设检验（t-test、F-test）
  • 相关性与协方差

3.3 回归与计量经济学（Econometrics）

  • 简单线性回归
  • 多元回归
  • 异方差、自相关
  • 时间序列（AR、MA、ARIMA）

4. Python 数据分析（Python for Finance）

4.1 Python 基础

  • 变量、函数、类
  • 文件操作
  • 异常处理

4.2 科学计算库

  • numpy
  • pandas
  • matplotlib、seaborn

4.3 数据获取

  • AkShare（中国市场）
  • Tushare（可选）
  • Yahoo Finance（全球市场）

4.4 数据清洗

  • 缺失值处理
  • 格式标准化
  • MultiIndex（在量化中非常重要）

4.5 可视化

  • 收盘价线图
  • K线图
  • 均线图
  • 成交量图

5. 量化投资基础（Quant Basics）

5.1 数据结构

  • 宽表 / 长表
  • 日期索引
  • MultiIndex：字段、股票

5.2 回测框架（Backtesting）

  • 调仓频率
  • t 决策、t+1 执行（A股特性）
  • T+1 卖出限制
  • 手续费、滑点
  • 订单撮合

5.3 经典策略

  • 趋势跟随：动量（Momentum）
  • 均值回归（Mean Reversion）
  • 双均线策略
  • RSI、MACD
  • 横截面多因子（Value、Growth、Quality）

5.4 因子分析

  • 因子暴露
  • 截面回归（IC）
  • 因子合成（线性加权）

5.5 风险管理

  • 最大回撤（MDD）
  • 夏普比率（Sharpe）
  • 风险预算
  • 仓位控制

🎓 金融系学生的课程体系（由浅入深）

其实金融专业的课程可以分成 四大模块：
（1）数学与定量基础
（2）经济学基础
（3）核心金融课程
（4）应用能力训练

我给你拆成具体课程，并解释每门课到底训练什么能力。

🔹 一、数学与定量基础（金融的底层能力）

金融专业不是只学“怎么炒股”，它的底层逻辑是数学和统计。

必修数学类

课程 训练能力
高等数学（微积分） 能看懂价格变动、风险变化的连续模型；奠定量化模型基础
线性代数 理解风险分散、相关性、多因子模型的重要工具
概率论与数理统计 金融数据分析、风险预测、回归模型的基础
统计学 / 回归分析 怎么用数据判断投资是否有效、“策略有没有显著性”
计量经济学（Econometrics） 金融中最重要的定量工具，用来建模预测、判断因果关系

🔍 总结：这部分让你具备 “读懂金融世界的数学语言” 的能力。

🔹 二、经济学基础（理解市场为何如此运行）

微观经济学

  • 市场供需如何决定价格
  • 公司如何定价、如何竞争
  • 理解消费者和企业的行为

宏观经济学

  • GDP、通胀、失业率、央行政策
  • 为什么加息会让股市下跌？
  • 一国经济结构怎么影响产业？

货币银行学

  • 货币如何创造
  • 银行体系如何运作
  • 美联储、人民银行的政策逻辑

🔍 总结：经济学让你理解“市场为什么这么走”，而不是靠情绪猜。

🔹 三、金融核心课程（真正的专业能力）

这些是“金融系学生的必修课”。

公司金融（Corporate Finance）

  • 如何计算公司价值
  • 投资项目能不能赚钱
  • 如何融资（股票融资、债券融资、银行贷款）
  • 股利理论、资本结构

核心训练：判断一家公司值不值得投。

投资学（Investments）

  • 股票、债券、基金如何定价
  • 风险与收益的关系（CAPM、Beta、Alpha）
  • 组合管理（如何分散风险）
  • 量化投资的基础理论

核心训练：如何构建一个有效投资组合。

金融市场与机构

  • 银行、券商、基金、保险公司如何运作
  • 市场的结构（一级市场、二级市场）
  • 监管体系

金融工程 / 金融衍生品（期权、期货、掉期）

  • 布朗运动、Black-Scholes 公式
  • 期权定价
  • 如何用衍生品对冲风险

核心训练：风险管理和衍生品交易的底层逻辑。

国际金融

  • 外汇市场
  • 汇率制度
  • 跨境资本流动

财务报表分析（很实用）

  • 如何读资产负债表、利润表
  • 如何判断公司是否健康
  • 现金流分析

核心训练：如何看企业的“真实”财务状况。

🔹 四、应用能力训练（职业技能）

这些不是课表上的名称，但每个金融专业学生都必须具备。

（1）Excel、Python、R、SQL

现代金融几乎离不开编程：

  • Python：量化回测、数据分析、金融工程
  • SQL：调取数据库
  • Excel（非常重要）：建模、财务分析、估值

很多学生会做：

  • 股票量化策略（回测）
  • 期权定价模型
  • 估值模型（DCF）

（2）商业分析与案例研究

  • 分析行业（互联网、汽车、能源…）
  • 看公司年报
  • 模拟投资决策

（3）金融建模比赛（CFA Ethics、CFA Institute、彭博比赛）

（4）实习

金融行业特别看重实习。

常见岗位：

  • 券商研究所（行业分析）
  • 投行（并购、IPO）
  • 基金公司
  • 商业银行
  • 咨询公司

🎯 金融系学生最终被训练成为怎样的人？

① 用经济学理解世界运行
